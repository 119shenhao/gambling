当前主分支仅保留项目入口，开发请查看 `dev` 分支；暂未配置 Cloudflare 生产数据库、生产部署或正式域名路由。**不得复用原脊椎论坛的 D1/R2、OAuth Client 或密钥。**

命名：简体中文为「戒赌社区」，繁体中文为「戒賭社區」；其他语言采用 **Problem Gambling** 的客观中立定位。所有语言是同一个论坛，业务数据共享；翻译不改变原文。
