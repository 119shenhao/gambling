# 戒赌社区 — 已确认产品需求

更新时间：2026-11-21。

## 名称与多语言定位
- 计划域名：`gambling.nbn369.com`。
- 简体中文：**戒赌社区**；繁体中文：**戒賭社區**，均可以倡导戒赌。
- **除此之外的所有语言**遵循英语 **Problem Gambling** 的客观、中立、事实讨论定位；允许自然译名，不采用劝戒宣传与其他未经确认的价值判断。
- 英文口号：**Real Stories. Real Impacts. Open Discussion.**
- 全语言**同一个社区**：共享用户、帖子、回帖和楼中楼；保存原文，翻译只作展示，不影响 SEO 原文语言标识。

## 内容与边界
- 基于真实经历，讨论赌博带来的经济、家庭、社交、心理和生活影响，允许讨论戒赌和复赌经历；不虚构故事、不替用户决定感受。
- 平台不推广赌博服务、博彩链接或投注技巧；坚持隐私、安全和守法的社区规则。
- 不强制登录浏览；发帖、回复、点赞、收藏等互动需主动登录。
- 独立的论坛业务数据库、管理权限与会话。相同 Google 账号由 Identity Center 识别为相同中心 User ID，但不公开跨论坛身份关联；打开另一个论坛不自动登录，点击登录时允许复用有效中心 SSO 会话。

## 技术复用
- 以 spine-community/main 作为稳定源码基础，保留公共论坛功能、回复、审核、统计、搜索、翻译与 SSR。
- 初步分类：个人经历、经济影响、家庭关系、情绪影响、戒赌经历、问题讨论。非中文分类翻译保持中性。
- 严禁迁入原论坛真实帖子/用户、Google Search Console 验证文件、D1/R2 UUID、Secret、生产发布工作流及采集同步任务。
- 先迁移到独立 dev 开发环境并检查 UI/分类/隐私，再注册 Identity Center 独立客户端，验证通过后另行申请生产上线。
